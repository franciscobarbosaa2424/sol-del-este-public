# Sol del Este

Full-stack web application for a handmade knitwear store, developed by Francisco Barbosa as part of his portfolio.

## Technologies

- Frontend: React, Vite and Tailwind CSS
- Backend: Node.js and Express
- Database: MySQL

## Getting Started

1. Import the database from the `BBDD` folder into MySQL.
2. Create a `.env` file in the backend folder with your database credentials:

   ```env
   DB_HOST=localhost
   DB_PORT=3306
   DB_USER=your_mysql_user
   DB_NAME=your_database_name
   DB_PASS=your_mysql_password
   ```

3. Run `npm install` in both the backend and frontend folders.
4. Start the backend and frontend in separate terminals by running `npm run dev` in each folder.
